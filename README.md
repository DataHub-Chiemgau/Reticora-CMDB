# Reticora-CMDB
Reticora ist eine SaaS-CMDB, die Netzwerk-, Server-, Strom- und Storage-Infrastruktur automatisch ausliest, in ein konsistentes Datenmodell überführt und sowohl menschenlesbar (intuitive Web-UI) als auch maschinenlesbar (REST-API, Webhooks, Export) bereitstellt. Zielgruppe sind ISPs und auf Netzwerke spezialisierte MSPs.
